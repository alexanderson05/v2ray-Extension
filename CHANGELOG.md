# Changelog

## 2.0.0-beta.1 (pre-release)

Designed by Alex Anderson.

- New: extension-only install (Developer mode → Load unpacked). On first open the extension detects its helper, downloads the Xray core automatically, keeps it updated and shows an "Everything is ready" confirmation.
- New: one-time setup file generated by the extension itself (no ID typing, no registry editing, no manual xray download); uses your Python or a private copy.
- New: redesigned dark UI, code-drawn logo and toolbar icon, animated credit line.
- New: ping test (TCP ping for all servers, sort by ping) and real-delay test through the proxy.
- New: log panel with Copy / Core log / Clear for easy bug reports.
- New: subscription manager (auto-update, usage and expiry, per-subscription refresh), `ss://` support, gRPC / HTTP/2 / HTTPUpgrade / XHTTP transports.
- New: routing modes (Global, Bypass Iran) and custom always-direct domains.
- New: safety watchdog, optional auto-reconnect, Persian and English UI.
- Changed: native host name is now `com.v2client.host` (run the new setup file once if you used v1.x).
